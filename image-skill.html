🛠️ How to

🖼️ Add a skill that makes images with Claude

Claude Code can make images for this site through DeepInfra's FLUX models. You add the skill once; after that you ask in plain words and the image is saved to the repo.

🧰 What you need

  • A DeepInfra account and an API key. Create the key in the DeepInfra dashboard.
  • Claude Code running in this repo (the content-calendar folder).
  • The skill and script, already in the repo: .claude/skills/deepinfra-images/SKILL.md and scripts/generate_image.py.

🪜 Steps

  1. 🔑 Set the key in your shell, never in a file

    Add this line to ~/.zshrc, then open a new terminal:

    export DEEPINFRA_API_KEY="your-key-here"

    The key is read from the environment. Don't commit it, paste it into a page, or leave it in a chat.

  2. 📂 Check the skill is in the repo

    Claude Code loads project skills from .claude/skills/. The skill is deepinfra-images. Start Claude Code in the repo folder so it's picked up.

  3. 🗣️ Ask for an image

    Describe the picture in plain English. Claude runs the script and tells you the saved path:

    Make an image: a flat illustration of a small robot delivering a package, bright colours, plain background.
  4. 🧪 Or run the script yourself
    python3 scripts/generate_image.py "a flat illustration of a robot delivering a package" --size 1024x1024

    Images are saved to images/generated/ with the date and a prompt slug in the name.

  5. 🧩 Use the image on a page

    Reference the saved path from the HTML, label it as AI-generated, and commit it with the page.

⚙️ Options

⚡ Default model

black-forest-labs/FLUX-2-pro: about $0.015 per image, good text and detail. Use --model black-forest-labs/FLUX-1-schnell for a cheaper draft.

🎨 Higher quality

Pass --model with another FLUX ID from DeepInfra, such as black-forest-labs/FLUX-1.1-pro. Keep each image under $0.10 and check the price on its page.

📐 Size

Pass --size, for example 1024x1024 or 1280x720 for a video frame.

📁 Output name

Pass --out images/generated/name.png to choose the file name.

⚠️ Limits
  • This works in Claude Code sessions in this repo. The dashboard chat agent edits files only and can't call DeepInfra.
  • Each image is billed by DeepInfra per image. Ask for one image at a time.
  • Label generated images as AI-generated. Don't present them as photos of real people or customers.
  • If you pasted your key into any chat, rotate it in DeepInfra and set the new one.
