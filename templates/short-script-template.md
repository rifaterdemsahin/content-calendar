# YouTube Short Script Template

Target Length: **35–55 seconds** (Optimal for completion rate and replay)

---

## Short Planning Metadata
- **Working Title / Concept:** [e.g., Stop Writing Repetitive Python Scripts]
- **Target Audience:** Developers, DevOps, AI Engineers, Tech Builders
- **Primary Hook Type:** [Contrarian / Problem-Agitation / Secret-Tool / Before-After]
- **Related Long Video or Skool Resource:** [Link / Name]

---

## 3-Beat Structure

### 1. The Hook (0 – 5 seconds)
> **Goal:** Stop the scroll. No greetings, no channel intros. Immediate visual + verbal disruption.
- **Visual:** [Screen recording with rapid movement, code disappearing, or face + high-contrast text overlay]
- **Verbal:** *"If you are still writing manual Python scripts for basic automation in 2026, stop. Look at this."*

### 2. The Core Value / Demonstration (5 – 40 seconds)
> **Goal:** Deliver 1 fast, concrete, high-impact insight or aha moment.
- **Beat A (The Problem - 10s):** *"Most people spend 4 hours debugging API connectors and auth tokens."*
- **Beat B (The Solution - 15s):** *"Instead, connect an n8n webhook node directly into an LLM tool-calling agent. Watch what happens when I trigger this."*
- **Beat C (The Proof - 10s):** [Screen recording showing output generated instantly with zero errors]

### 3. The Climax & Call to Action (40 – 55 seconds)
> **Goal:** Guide viewer to next action (either related long video or Skool resource).
- **Verbal:** *"I put the entire workflow JSON and prompt template inside our free Skool community. Link in the channel bio and pinned comment."*
- **Visual:** Quick 2-second screen flash of the Skool Classroom resource page.

---

## Production Checklist
- [ ] Text overlays kept within 9:16 safe zones (avoid bottom 20% and top 10%).
- [ ] Fast pacing (cuts every 2.5 - 4 seconds).
- [ ] Subtitles / Captions auto-generated with emphasized keywords.
- [ ] Audio normalized; background music kept low (-18dB).
