Dashboard 💎 Value Check
Before you make it

Is there genuine value in every video?

Each planned video is scored on five questions and has a written rationale for why it is useful to its audience. The data lives in data/videos.json under each video's value block, next to the title, hook and conversion target.

The scores are a first draft by Claude from your plan and channel data. They are judgements, not measurements, so change any you disagree with.

    How to update it

    • Here: press Edit on a card, change any field, then press Done. Your edits are kept as a draft in this browser. Press Copy JSON and paste it over data/videos.json, or use the dashboard chat to apply it.
    • Dashboard chat: describe the change ("raise the proof score for w3-item-2 to 2 and add why"). The chat edits the file, merges and publishes.
    • On GitHub: edit data/videos.json directly. A new video with no value block shows up here as "Not reviewed", and the test suite fails until it has one.
