Dashboard 🔑 Add the YouTube API key On track →
Why

A key lets the numbers update by themselves

With a YouTube Data API key, a scheduled job on Fly.io pulls your views, comments and subscriber count every day and saves them. The analytics and on-track pages then show current numbers without you pasting a Studio export. The key only reads public data. It cannot change your channel.

Do not paste the key into chat, a file or a commit

Anything typed into this chat is stored in the conversation. A key in the repo is public. Put it only in your own terminal (step 3) and in Fly secrets (step 4). If a key ever leaks, delete it in Google Cloud and create a new one.

🪜 Steps

1 · Create the key in Google Cloud
  1. Open console.cloud.google.com and sign in with the Google account that owns the channel.
  2. Create a project, e.g. content-calendar.
  3. Go to APIs & Services → Library, search YouTube Data API v3, and click Enable.
  4. Go to APIs & Services → Credentials → Create credentials → API key.
  5. Click the new key, then under API restrictions choose Restrict key → YouTube Data API v3. Save.
2 · Check it works (optional, takes a minute)

Run this in your terminal from the repo. The key is typed in silently and lasts only for this window.

cd ~/Projects/content-calendar
read -s YOUTUBE_API_KEY && export YOUTUBE_API_KEY
python3 scripts/pull_youtube_stats.py
python3 scripts/studio_stats.py data/studio/youtube-api-$(date +%F).json

You should see "wrote … 30 videos" (or your current count). If you see an error, copy the message back and I'll fix it.

3 · Save it for the scheduled job on Fly.io

Secrets are encrypted by Fly and never appear in the repo.

fly apps create rifat-stats-cron
read -s KEY && fly secrets set --app rifat-stats-cron YOUTUBE_API_KEY="$KEY" && unset KEY
read -s CONN && fly secrets set --app rifat-stats-cron AZURE_STORAGE_CONNECTION_STRING="$CONN" && unset CONN

The Azure string is the storage account connection string (Azure portal → Storage account → Access keys → Connection string). It is the same account the function app uses.

4 · Deploy the job and schedule it daily
fly deploy --config jobs/stats/fly.toml --dockerfile jobs/stats/Dockerfile --app rifat-stats-cron
fly machine run --app rifat-stats-cron --schedule daily --restart no --region lhr <image from the deploy output>

Check the schedule command against fly machine run --help on your Fly CLI version. Run the job once by hand with fly machine start to confirm the first run.

5 · Confirm it worked

Open On track. The "Source" line shows the latest run time once the job has saved its first file. Until then the page uses the last manual snapshot.

🔑 What the key can and cannot do

  • It can read public video stats and the public subscriber count.
  • It cannot see watch hours, retention, click-through rate or traffic sources. Those need YouTube Analytics (OAuth) or the Studio export.
  • It cannot upload, edit or delete anything on the channel.

Matches requirement IN-4 and KV-12 on the requirements page. The key can also live in Azure Key Vault instead of Fly secrets if you prefer one vault for everything.
